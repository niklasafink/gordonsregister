# Sicherheit

## Lücke melden

Bitte keine öffentlichen Issues für Sicherheitslücken. Nutze stattdessen auf GitHub **Security → Report a vulnerability** (private Meldung an den Maintainer).

Hilfreich sind: betroffene Komponente (Add-in oder Proxy), Version oder Commit, Schritte zum Nachstellen und die mögliche Auswirkung.

Du bekommst in der Regel innerhalb von sieben Tagen eine erste Antwort.

## Umfang

Betroffen ist der Code in diesem Repository. Jede Organisation betreibt ihren Proxy selbst; für Konfiguration, Updates und Betrieb einer Instanz ist ihr Betreiber verantwortlich.
